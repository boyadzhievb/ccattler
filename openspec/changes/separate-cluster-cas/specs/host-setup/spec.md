# Spec Delta

## ADDED Requirements

### Requirement: setup.sh installs the etcd and gate CAs and limits etcd's trust
The `setup.sh` generated by `cca init` SHALL install the etcd CA, the gate CA and the etcd client certificate under
`/etc/ccattler/pki` (keys at 0600, owned by root). It SHALL configure etcd to trust only `etcd-ca.pem`. The units it
writes SHALL pass the etcd client certificate and the etcd CA to `cca server` and `cca agent` for their etcd
connections.

#### Scenario: Generated etcd trust and units
- **GIVEN** the `setup.sh` generated by `cca init`
- **WHEN** it is read
- **THEN** the etcd TLS drop-in sets `ETCD_TRUSTED_CA_FILE=/etc/ccattler/pki/etcd-ca.pem`, and the `cca-server` and
  `cca-agent` units pass `--etcd-cert /etc/ccattler/pki/etcd-client.pem` and `--etcd-ca /etc/ccattler/pki/etcd-ca.pem`
- Test: `TestSetupScriptUsesEtcdCA`

#### Scenario: A fresh cluster works with three CAs
- **GIVEN** a fresh host set up with the guide (cca init and setup.sh)
- **WHEN** `cca-server` and `cca-agent` start and a service is applied
- **THEN** etcd is healthy over TLS, the node is alive and the service runs
- Check: `install-host:three-cas` (by hand on a fresh VM); the full Deploy Testbed run
